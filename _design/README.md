# Оформление магазинов

concepts.json содержит разные статические композиции 18 магазинов. Все интерактивные особенности первого экрана удалены по просьбе пользователя. Общие визуальные варианты — individuality.css; крупная типографика, мобильное меню и оформление иконок — readability.css. Копии находятся в каждой автономной папке сайта.
