# Концепции оформления

concepts.json описывает индивидуальную особенность каждого из 18 магазинов. Каждый сайт автономен: его HTML, CSS и JavaScript находятся в соответствующей папке. Файлы individuality.css и individuality.js здесь — общий поддерживаемый исходник поведения и визуальных вариантов; папки сайтов содержат копии, чтобы их можно было публиковать независимо. Сборка не требуется.
