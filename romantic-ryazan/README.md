# Romantic — демонстрационный сайт

Откройте index.html в браузере. Все фотографии хранятся локально, сервер и сборка не требуются. Внешнее соединение используется только для Google Fonts и переходов по ссылкам.

Источник: https://yandex.ru/maps/org/9569254761/
Дата проверки: 10.11.2026. Данные магазина: data/content.json. Полный опубликованный прайс: data/products-source.json. Галерея — примеры работ, не подтверждение наличия. Цены и условия необходимо согласовать с магазином.

Визуальный ориентир: Салатовая надпись Romantic и розовый цветок на настоящем логотипе.
