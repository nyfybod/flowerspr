# Flowerspr

[Все 18 сайтов](https://nyfybod.github.io/flowerspr/)

Каждый магазин находится в отдельной папке и работает самостоятельно. Сборка не нужна. Интерактивные особенности первого экрана удалены, разные композиции сохранены. Общие коррекции размера текста и меню находятся в readability.css каждого сайта. Все существующие ссылки на соцсети и мессенджеры представлены иконками. Каталог, фильтры и просмотр фотографий работают как раньше.

Ответы FAQ раскрываются и закрываются плавно; управление — мышью или клавиатурой. prefers-reduced-motion отключает анимацию. Native details остаётся рабочим без JavaScript.
