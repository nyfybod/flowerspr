Цены, фотографии и исходные сведения сохранены из предыдущей версии. Новые интерактивы помогают выбрать настроение и сформулировать пожелание; они не оформляют заказ и не принимают оплату. Файлы individuality.css и individuality.js каждой папки отвечают за её индивидуальный первый экран. Общий перечень концепций — _design/concepts.json, подробности — DESIGN.md.
