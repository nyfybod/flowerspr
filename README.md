# Flowerspr

[Все 18 сайтов](https://nyfybod.github.io/flowerspr/)

Каждый магазин находится в отдельной папке и работает самостоятельно. Сборка не нужна. Интерактивные особенности первого экрана удалены, разные композиции сохранены. Общие коррекции размера текста и меню находятся в readability.css каждого сайта. Telegram и ВКонтакте представлены иконками. Каталог, фильтры и просмотр фотографий работают как раньше.
